# ToastFlix Audio Sidecar - Add-on per Home Assistant OS

Add-on non ufficiale per eseguire [toastflix-sidecar](https://github.com/qwertyuiop8899/toastflix-sidecar)
(audio italiano Dual Audio 4K/FHD per ToastFlix) su Home Assistant OS.

## Installazione

1. Impostazioni -> Add-on -> Store -> menu (tre puntini) -> **Archivi**.
2. Aggiungi: `https://gitlab.com/TUO_UTENTE/ha-toastflix-sidecar`
3. Installa **ToastFlix Audio Sidecar**, configura le opzioni e avvia.
4. Apri `http://IP_DI_HA:3169` e usa "Verifica Connettivita".

Il repository deve essere **pubblico** su GitLab, altrimenti HA non riesce a clonarlo.

Vedi `toastflix_sidecar/DOCS.md` per le opzioni.
